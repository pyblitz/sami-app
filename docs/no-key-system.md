# Sami App — No-Key System

Sami App works with files, browser and local tools only. The owner buys NO API key,
enters NO API key, and is NEVER asked for a password, OTP or API key in chat — for anything.

## What it uses instead
- Files + local drafts: templates, rates, rules and checklists in this repo.
- Browser: the owner's own already-signed-in sessions where they exist. If a session
  has expired, he signs in himself on his own device/browser — Muse never types his password.
- Local app: HTML/CSS/JS that runs in his own browser, saves nothing to a server,
  sends nothing to any account.

## What it will NEVER use
- No paid API key, no paid scheduler, no paid posting service, no paid AI voice/video API.
- No API key pasted into chat, a file, a repo, a screenshot or a log.
- No "just enter your key here" step anywhere in this app. A feature that cannot work
  without a key is redesigned to work without one, or honestly marked as needing the
  owner's own free sign-in on that platform, done by him.

## Correction (do not lose this)
- The old Jarvis draft said Google OAuth Client ID was "his own setup step".
  That step is REMOVED. Google sign-in in this app is: NO Client ID, NO OAuth app
  setup required. Platform work goes through the owner's own signed-in session,
  or his own device sign-in — exactly like his other chats already work.

## Cost, honestly
- API keys: Rs 0, none needed.
- Separately, only if he chooses it later: his own internet/device, a domain/hosting
  for a custom website (not required), a Play Store developer account for a real
  Play Store listing (not promised, not included). None of those is an app API key.
