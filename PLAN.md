# Sami App — Merged Plan (1 Nov 2026)

**Repo:** `github.com/pyblitz/sami-app` (proposed; formerly Jarvis, renamed Sami 31 Oct 2026).
**Status:** Merged file set, published on GitHub per owner order 1 Nov 2026, then
downloaded and tested. This plan records what was built, not a promise of more.

## Merged sources (never publish both originals)
- GitHub-chat draft (`jarvis-app-draft`): PWA shell, templates, designer,
  promotions, automations, logo, manifest, service worker.
- Jarvis-chat draft: Sami & Sara characters file + no-key system plan.
- Reconciliation: OAuth Client ID step REMOVED (superseded 31 Oct 16:51 no-key rule
  and 1 Nov no-API-key order). Login in this app is a disabled placeholder.
  Auto-post/live plans were NOT merged — no auto-publish in this app.

## What the app does (6 sections)
1. Home — intro + section links.
2. Templates Maker — 10 concept presets (4 design services + 6 concept brands).
3. Designer — canvas editor, headline size slider, PNG download.
4. Promotions — caption from typed facts only, copy only, no auto-post.
5. Automations — local checklists, localStorage persistence, no account login.
6. Sami & Sara Discuss — Sami plan/logic, Sara QC/risk/user view, joint conclusion,
   7 lenses, local text only, no LLM, no API, no voice call.

## Honest limits
- Responsive web app + PWA shell. NOT a Play Store listing, NOT an APK.
- No backend, no database, no server data — data stays in the browser.
- Sami & Sara are fictional assistant characters, not real people. No romantic
  roleplay, no real-relationship claim, no fake AI claim. A real LLM/API step is
  separate and needs the owner's separate approval; no key is ever asked in chat.
- No publish, post, message, spend or setting change happens from this app itself.
  Publishing, if any, is done by the owner himself on his own signed-in session.

## Devices
Phone, tablet, laptop/desktop — one responsive codebase, no separate Android/iOS code.

## What is NOT in this app
- No auto-post, no DM blast, no group spam, no copied brand logos.
- No Google OAuth setup, no Client ID, no Client Secret, no token, no password, no OTP.
- No LICENSE file yet (MIT is a proposal only).
